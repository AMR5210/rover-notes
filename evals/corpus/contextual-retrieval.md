# Contextual retrieval

Each chunk is annotated with a short description of its place in the source document
before it is indexed.

The annotation is generated by claude-haiku-4-5, capped at 100 tokens, and prepended to
the chunk text for both the dense vector and the tsvector. The stored chunk body is left
unchanged, so a citation still resolves to the original span. A chunk opening with "This
approach was reversed" carries no retrievable subject on its own; the prefix restores the
document and section it belongs to.

Annotation runs once per chunk at ingest and places the whole source document in the
prompt each time. The document is sent as a cached prefix, which is what keeps the pass
affordable at roughly six chunks per document.

The technique's published result is a 35 percent reduction in retrieval failure rate,
rising to 49 percent when paired with a lexical channel. Whether it reproduces on this
corpus is measured against the golden set before the pass is kept, and the annotation
model is pinned so the stored prefixes stay comparable across runs.
